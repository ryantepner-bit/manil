# MANDELBROT overlay for LMMS

Everything in this folder is copied over a clean LMMS checkout
(sysfce2/DAW_lmms, pinned in `.github/workflows/mandelbrot-lmms.yml`) before building.
Files here either are new (fractal engine, ambient effects, templates) or are full
replacements of the LMMS file with the same path. LMMS is GPL-2.0-or-later, so this is too.
